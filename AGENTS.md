# For every agent

This is for Claude, Codex, Antigravity, Cursor, FleetCrown, and anything else.
Do not keep a private copy of these facts. Read the registers. If a fact is not
in a register, it is not true yet.

- Serve (port, process, host): `fleetcrown/scripts/hetzner/apps.conf`
- Org facts (public name, unregistered, house address, host): `registers/org.json`
- Display name and who the work is for: the product README title, not the
  apps.conf hostname. A rename in a README that never reaches the page is a bug.
- An `orangecat.ch` name is an address on the Hetzner box, not a product of OrangeCat.
- GitHub Pages is not a host.
- Design: `@bitbaum/design-tokens`. A site is data rendered by `sitekit`.
- Do not add auth, ai-kit, or bip-kit unless the page needs a signed-in user,
  a model, or a public changelog.
- Public name is Cato. Nothing here is registered.

A page that types the portfolio is a copy. Generate it, or do not ship it.
